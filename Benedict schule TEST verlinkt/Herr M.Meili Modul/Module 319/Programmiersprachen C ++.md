``` 
[[include]] <iostream>



using namespace std;

int main() {
    short Zahl = 32767;
	cout << "Mini-Rechner" << endl;
    cout << "Bitte geben Sie eine Zahl ein: ";
    cin >> Zahl;

    cout << "Ich rechne: " << Zahl << " + " << Zahl << endl;
    cout << "Das Ergebnis lautet: " << Zahl + Zahl << endl;

    cout << "\nDruecken Sie die Enter-Taste.";

    cin.get();

```

**`cout` und `cin` sind in C++ für Ausgabe und Eingabe da.**

- **`cout` = etwas auf dem Bildschirm anzeigen**  
    **Beispiel: `cout << "Hallo";`**
- **`cin` = etwas vom Benutzer eingeben lassen**  
    **Beispiel: `cin >> Wort;`**

**Merksatz: `cout` gibt aus, `cin` liest ein.**

`endl` bedeutet: **Neue Zeile**.
