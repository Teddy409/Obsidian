Der Ablauf ist ungefähr so:

1. **Kunde**
    - stellt eine Offertanfrage / Submission
    - oder macht direkt eine Produktbestellung
2. **Beratung und Verkauf**
    - Kundenwunsch wird aufgenommen
    - Angebot bzw. Auftrag wird bearbeitet
3. **Auftragsplanung**
    - es wird geplant, was produziert werden muss
4. **Beschaffung**
    - benötigte Materialien werden beim Lieferanten bestellt
5. **Lieferant**
    - liefert die Ware an das Unternehmen
6. **Lagerung**
    - Material wird gelagert
7. **Produktion**
    - das Produkt wird hergestellt
8. **Spedition und Fakturierung**
    - Produkt wird versendet
    - Rechnung wird erstellt
9. **Kunde**
    - erhält das fertige Produkt
